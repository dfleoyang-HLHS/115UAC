# 115 志願選擇庫

依 115 學年度學測成績與五標，篩選繁星推薦、個人申請、分發入學、四技申請的校系，並可加入選擇庫並排比較。

直接用瀏覽器開啟 `index.html` 即可使用（需與 `data.js` 放在同一資料夾）。原住民族學生升學專區為 `indigenous.html`。

## 資料檔

| 檔案 | 內容 |
|---|---|
| `star115_校系分則.csv` / `star115.db` | 115 繁星推薦校系分則（64 校、1664 校系） |
| `apply115_校系分則.csv` / `apply115.db` | 115 個人申請校系分則（64 校、2206 校系） |
| `115分發入學_校系分則.csv` | 115 分發入學招生簡章校系分則（60 校、1764 學系） |
| `115四技申請_校系分則.csv` | 115 四技申請入學系組資料（58 校、593 系組），來源為 `四技申請_115原始資料/` 內的官方 Excel |
| `114分發入學_校系分則.csv` | 114 分發入學招生簡章校系分則（61 校、1780 學系） |
| `115繁星推薦_錄取標準.csv` | 115 繁星推薦各校系錄取標準（含外加名額、第八類學群篩選），原始 PDF 在 `繁星115錄取標準_PDF/` |
| `115申請入學_篩選標準.csv` | 115 申請入學各校系第一階段篩選標準（圖片經 OCR 辨識），原始圖片在 `申請115結果_原始資料/` |
| `115申請入學_分發標準.csv` | 115 申請入學各校系分發最低標準（各名額類別分列） |
| `115分發入學_錄取結果.csv` | 115 分發入學各系組最低錄取分數及錄取人數，來源 `115_result_school_data.pdf` |
| `114繁星推薦_錄取標準.csv`、`114申請入學_篩選標準.csv`、`114申請入學_分發標準.csv`、`114分發入學_錄取結果.csv` | 114 學年度各管道錄取結果（格式同 115；114 申請入學篩選標準的檢定與倍率亦為 OCR 辨識），分發入學來源 `114_04.pdf` |
| `star_school_pct.json` | 繁星推薦各校「在校學業成績全校排名百分比」標準 |
| `data.js` | 網頁用資料，由 `build_data.py` 產生 |

資料來源：大學甄選入學委員會 115 學年度校系分則、大學分發入學招生簡章、技專校院招生委員會聯合會 115 學年度四技申請入學招生資料。

## 程式

| 檔案 | 用途 |
|---|---|
| `build_data.py` | 由 db / CSV 產生 `data.js` |
| `build_caac.py` | 由四技申請官方 Excel 產生 `115四技申請_校系分則.csv` |
| `export_csv.py` | `apply115.db` 匯出 CSV |
| `export_star_csv.py` | `star115.db` 匯出 CSV |
| `build_star_result.py` | 下載並解析繁星推薦錄取標準 PDF |
| `build_apply_result.py` | 抓申請入學分發標準網頁、下載篩選標準圖片 |
| `ocr_apply_sieve.py` | 以 OCR 辨識申請入學篩選標準圖片 |
| `parse_uac_result.py` | 解析分發入學錄取結果 PDF |
| `parse_recruit_pdf.py` | 解析分發入學招生簡章 PDF：`uv run --with pdfplumber python parse_recruit_pdf.py <pdf> <輸出csv> <起始頁> <結束頁> <頁碼偏移>` |

## 歷年錄取結果

網頁查詢結果右側的「歷年錄取結果」由 `build_data.py` 依檔名開頭的學年度自動讀取，新增年度時只要放入同樣格式、檔名以年度開頭的 CSV（例如 `114繁星推薦_錄取標準.csv`），重跑 `build_data.py` 即可。

各年度校系代碼可能重新分配給別的系，所以歷年資料以「學校＋系名」對應到目前網頁的校系；系名只有細微差異時，才以相同代碼且名稱相似度 ≥ 0.75 補對應。改名或整併的校系不會對應。
